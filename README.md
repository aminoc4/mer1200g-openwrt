# Mercury MER1200G v1 OpenWrt

水星 MER1200G v1 系列的实验性 OpenWrt 适配。已在一台 Ver1.1 设备验证内核启动、RTL8367S 当前连接口、中文 LuCI、JFFS2 overlay，以及软件重启后的 UCI 配置和 SSH 密钥保留。不能据此认定所有硬件版本、所有网口、无线或日常使用功能都已验证。

这里区分两个版本，内核和网络功能保持同一基线：

| 版本 | 界面 | 状态 |
| --- | --- | --- |
| `stock-luci` | 上游 LuCI 的布局和操作方式 | 持久化候选已构建，正在完成离线审查，尚未刷入验证 |
| `compact-cn` | 轻量中文首页、常用功能入口及高级设置 | 已刷入并验证软件重启后的配置持久化；保留原生 LuCI 后端 |

“原版界面”指未做界面定制的 LuCI，**不是水星原厂固件**。实验阶段隐藏尚不支持的刷写入口；这项限制会在两个版本中保持一致。

定制版以简体中文、清晰的联网/设备/IPv6规则管理为目标，沿用原生 LuCI 表单，避免大型前端框架、外部字体、CDN 和遥测。地区界面适配不代表擅自更改 DNS、上网方式或放行外网访问。

## 当前边界

中文持久版已在一台 Ver1.1 上验证 SquashFS + JFFS2 overlay、提交配置后软件重启保留，以及 SSH 密钥保留；bootloader、设备信息与 ART 等保护区哈希未变。无线关闭，所有外部端口先作为 LAN；拨号、外网 IPv6、其它面板网口和启动失败后的恢复仍未验收。常规 sysupgrade 和网页刷写入口仍禁用。

本仓库已提供板级源码、补丁、固定版本构建配置及界面源码。没有通用刷写教程或自动安装授权。不要复用其他内核下的数字 MTD 分区号；同名设备节点的含义可能不同。

## 发布内容

未定制界面版本位于 [variants/stock-luci](variants/stock-luci)，轻量中文首页位于 [variants/compact-cn](variants/compact-cn)。两者分别保留，构建及实机验证结果分开记录。当前未发布可直接刷入的固件二进制或已签名 APK。

不发布任何个人设备的完整闪存备份、bootloader 转储、ART/无线校准数据、配置备份、SSH 私钥、签名私钥、凭据或实机日志。Git 仓库仅包含经过明确筛选的软件文件。
