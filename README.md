# Mercury MER1200G v1 OpenWrt

水星 MER1200G v1 系列的实验性 OpenWrt 适配。已在一台 Ver1.1 设备验证内核启动、RTL8367S 当前连接口、SSH 和 RAM 中的 LuCI。不能据此认定所有硬件版本、所有网口、无线或日常使用功能都已验证。

这里区分两个版本，内核和网络功能保持同一基线：

| 版本 | 界面 | 状态 |
| --- | --- | --- |
| `stock-luci` | 上游 LuCI 的布局和操作方式 | 持久化候选已构建，正在完成离线审查，尚未刷入验证 |
| `compact-cn` | 可选轻量中文界面、常用功能入口及高级设置 | 准备中，不替换 LuCI/RPC/防火墙后端 |

“原版界面”指未做界面定制的 LuCI，**不是水星原厂固件**。实验阶段隐藏尚不支持的刷写入口；这项限制会在两个版本中保持一致。

定制版以简体中文、清晰的联网/设备/IPv6规则管理为目标，沿用原生 LuCI 表单，避免大型前端框架、外部字体、CDN 和遥测。地区界面适配不代表擅自更改 DNS、上网方式或放行外网访问。

## 当前边界

目前设备运行 initramfs 验收版：网页和配置只保存在 RAM，重启丢失。无线关闭，所有外部端口先作为 LAN；尚未完成拨号、外网 IPv6、持久化或完整恢复路径验收。持久化候选使用独立构建目录，不能直接作为 sysupgrade 固件使用。

本仓库初始整理中，源码导出、构建说明、许可清单和候选工件尚待完整审查。没有通用刷写教程或自动安装授权。不要复用其他内核下的数字 MTD 分区号；同名设备节点的含义可能不同。

## 发布内容

计划发布板级源码、补丁、固定版本构建配置、界面可选包和对应校验值。原版和定制版分别标记，构建及实机验证结果分开记录。固件候选须标明实验状态，并附上对应源码和许可信息。

不发布任何个人设备的完整闪存备份、bootloader 转储、ART/无线校准数据、配置备份、SSH 私钥、签名私钥、凭据或实机日志。Git 仓库仅包含经过明确筛选的软件文件。

## 许可证

OpenWrt、Linux、LuCI 及各软件包分别适用其原有许可证，原有版权和声明必须保留。本仓库整理完成前不对第三方组件统一重新授权。后续新增界面文件会附明确许可证；二进制发布须同时核对对应源码和再分发要求。
