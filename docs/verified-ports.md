# MER1200G Ver1.1 机身网口与交换机映射

在一台 Ver1.1 上，通过管理电脑保持连接、另一台电脑逐口插拔，核对外置 RTL8367S（switch1）的链路变化确认如下映射。这里的机身数字指外壳印刷编号。

| 机身编号 | switch1 内部端口 | 当前实机配置 |
| --- | --- | --- |
| 1 | 0 | WAN，PPPoE；WAN6 共用 |
| 2 | 1 | LAN |
| 3 | 2 | LAN |
| 4 | 3 | LAN |
| 5 | 4 | LAN，管理电脑验证可达 |

内部端口 7 是 CPU 连接，不是额外的机身网口。不要把 SoC 内置 switch0 的端口号与外置 switch1 混用。

实机 LAN VLAN 1 成员为 `1 2 3 4 7t`；WAN VLAN 2 成员为 `0 7t`。CPU 侧分别使用 eth0.1、eth0.2；机身外部网口均为 untagged，内部 VLAN 2 不代表运营商业务 VLAN。光猫桥接侧是否已处理业务 VLAN，需要实际接线与 PPPoE Discovery 验收，不能机械叠加 VLAN 标签。

1、2、4、5 号口本次观察到 1000Mbps；3 号口本次观察到 100Mbps，线缆/接触/协商原因尚待复测。链路接通不等同于 PPPoE 已成功或吞吐已达标。

本记录中的 WAN/LAN 角色是已提交到实机 overlay 的配置，不表示现有已安装 ROM 的恢复出厂默认值已改变。2～4 号口当前设为 LAN，可手动配置角色；没有实现自动识别 WAN/LAN。旧实验记录中“3 号口为 WAN”属于调整前的临时接线方案。

当前接线：光猫桥接业务绑定的 LAN 口 → 路由器机身 1 号口；电脑 → 5 号口或 2～4 号口。拨号与 WAN6 配置在角色调整前后逐字节一致。
