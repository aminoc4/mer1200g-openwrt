# 开发记录

## 当前实现

daily-cn-v2 已在 MER1200G Ver1.1 实机运行。配置、SSH 密钥和三个 AP 在正常软件重启后保留；五个机身网口均已观察到 1000Mbps 全双工连接。

当前实机网口配置为 1 号 WAN、2～5 号 LAN，保存在 overlay 中。现有安装镜像的 ROM 初始网络配置仍为全 LAN；后续构建统一默认角色时，按已确认的机身映射更新。

IPv6 采用电脑临时桥接现有上游的方式，完成了路由器 SLAAC、公网路由、IPv6 DNS、HTTPS 下载和报文大小测试。局域网电脑到路由器的 IPv6 通信也已通过。

## 首装 JFFS2 初始化修正

首次预置 overlay 时遗漏了根目录 `.fs_state -> 2` 符号链接，fstools 因此将其判定为未初始化并清空预置内容。随后在原生初始化完成的 JFFS2 上恢复原配置，完成重启持久化验收；生成器与校验器已补充 READY 符号链接的语义检查。原私有安装镜像已归档停用。
