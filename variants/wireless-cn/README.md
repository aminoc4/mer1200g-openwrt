# MER1200G Ver1.1 双频无线增量源码

基于 `../compact-cn/firmware`，保留其精简中文首页和原生 LuCI。原版 LuCI 源码仍保存在 `../stock-luci`，原有有线版本也保留。本目录是构建增量与验收记录，不是通用刷机包或官方支持声明。

在基础版本准备好构建目录后，用本目录 `board.dts` 替换 `target/linux/ramips/dts/mt7620a_mercury_mer1200g-v1.dts`，用 `config.full` 替换 `.config`，将 `files/` 合入构建目录；按基础版本固定依赖和构建脚本执行 defconfig、构建和离线封装。未重新进行全新环境可重现构建。不得直接使用官方 C5 固件代替本机分区布局。

新增 rt2800-soc、mt76x2、wpad-basic-mbedtls、iw、iwinfo 和无线监管数据库。ART 只读，2.4GHz 校准偏移 0，5GHz 偏移 0x1000，每个单元 512 字节。没有包含任何设备校准内容、备份或私钥。

首次生成无线配置时国家为 CN，两个射频及默认热点关闭。原厂 EEPROM 的默认 MAC 不是每台设备唯一：在本机新生成的默认配置上执行 `sh postinstall-unique-ap-macs.sh`，使用已验证的本机出厂 LAN 地址派生两个本地管理地址。这个修正已在实机配置中应用并提交；它不在已安装的 SquashFS 镜像内。用户需自行设置无线名称、WPA2 密码后启用。

## 一台 Ver1.1 实机的有限验收

- 仅更新物理偏移 0x40000 至 0x940000，共 144 个 64KiB 块；保留 overlay、bootloader、厂商元数据和 ART。
- 每块读回和完整 9MiB 哈希校验通过，保护区域前后完全一致。
- 持久系统启动、原有六份系统/网络配置哈希一致；两路 PHY 均正常加载。
- 两路被动扫描成功，临时隔离 WPA2 热点均达到 AP-ENABLED；测试热点已删除。
- 6 轮 4MiB 双向 RAM 传输逐字节一致，网卡收发错误与丢包计数未增长。
- 未进行真实无线客户端关联、漫游、吞吐或长时间无线压力测试。
- 可写 overlay 约 3.64MiB 空闲，SquashFS 4,221,604 字节；无线关闭时可用 RAM 随缓存变化约 59–63MiB。

本目录不提供一键安装器。常规 sysupgrade/mtd 仍被阻止；失败启动恢复尚未验证。不得把构建候选窗口末尾的 overlay 初始化标记覆盖到已有用户配置。二进制发布仍须按基础版本 NOTICE 补齐对应源码与许可证。
